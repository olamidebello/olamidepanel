Privacy notice

Updated October 19, 2026

This directory does not request an account, precise device location, or payment information. Its page code does not set cookies or include analytics or advertising trackers. If you choose a preferred country, its identifier is saved in local storage on your device until you change or clear that preference.

Your browser sends your IP address, browser information and request details to the hosting server. The hosting operator may record access and error logs for service operation and security. Search filtering runs in your browser and is not submitted by the page.

Weather previews pass through this server to the listed country edition servers. Those servers receive the directory server IP address and selected public city coordinates, and obtain weather data from their configured providers. If an edition is unavailable, this directory requests a forecast directly from Open-Meteo using the featured city coordinates. The provider receives the server IP address. Temperature unit choices remain in page memory. The Android app stores your country choice in its local preferences; clearing app data removes it. The download section contacts GitHub to find a published APK. GitHub receives your IP address and request information; downloading an APK opens GitHub. Clicking a country link opens that edition, whose privacy notice applies.

Retention of server logs depends on the hosting configuration; this page does not establish a fixed retention period. Contact the operator through the contact route published on https://olamideolatayobello.com/ for privacy requests or questions. This notice must be updated if analytics, advertising or accounts are added.
